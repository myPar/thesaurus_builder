* **Рель** — это специфический тип модели машинного обучения, который часто используется для решения задач, связанных с классификацией и регрессией. Рель обычно представляет собой нейронную сеть, которая имеет сложную структуру и может эффективно обрабатывать большие объемы данных.

* **Behavior Cloning** — это метод обучения, который основан на воспроизведении поведения роботов или машин. Этот метод использует данные о поведении робота или машины, чтобы обучить искусственный интеллект, который будет повторять это поведение в реальных условиях.

* **Cross-Entropy Method** — это метод обучения, который используется для улучшения точности модели в задачах регрессии. Этот метод использует функцию потерь, которая сравнивает прогнозы модели с реальными данными, чтобы вывести лучший вариант обучения.

* **Supervised Learning** — это метод обучения, который использует обученные модели, которые были обучены на основе данных, где метки известны. В этом методе модель обучается на основе примеров с метками, которые были предоставлены заранее.

* **Unsupervised Learning** — это метод обучения, который не использует метаданные для обучения модели. В этом методе модель сама ищет признаки в данных, без использования метаданных.

* **Reinforcement Learning** — это метод обучения, который позволяет обученному устройству принимать решения в реальном времени, чтобы максимизировать определенный наградный сигнал. * __Свёрточный слой__ — слой нейронной сети, предназначенный для автоматического извлечения признаков из изображений. Он работает за счёт применения к изображению набора обучаемых фильтров (__ядер свёртки__).

* __Ядро свёртки__ — это набор обучаемых параметров в свёрточном слое нейронной сети, предназначенный для выявления характерных паттернов на изображении. В процессе обучения веса ядра настраиваются на основе статистических данных всего обучающего датасета. Ядро последовательно проходит по входному изображению (или по активации предыдущего слоя) и на каждой позиции вычисляется значение, отражающее степень соответствия данного участка изображения паттерну, закодированному в ядре. Математически это реализуется как скалярное произведение ядра и соответствующего фрагмента изображения с добавлением смещения (bias). Результатом применения одного ядра является карта признаков (feature map). В каждом свёрточном слое, как правило, используется несколько ядер, каждое из которых отвечает за извлечение своего паттерна, формируя тем самым многоканальный выходной тензор, где число каналов соответствует числу ядер в слое.

* __Рецептивный фокус__ — это параметр, определяющий, сколько пикселей анализирует нейронная сеть в каждой изображенной области при выполнении свертки. Сходимость обеспечивает повышение качества модели путем минимизации ошибок.

* __Learning Rate__ — скорость обучения, то есть величина, которая определяет как быстро нейронная сеть будет изменять свои веса в процессе обучения. В некоторых случаях это может быть постоянная, в других — увеличивается с течением времени.

* __ShadowLink__ — улучшение оптимизации, которое позволяет уменьшить разницу между реальным и прогнозируемым значением ошибки, что позволяет модели обучаться быстрее и лучше.

* __Momentum Gradient Descent__ — алгоритм оптимизации, использующий компоненты скорости (моментум) для предотвращения переобучения и ускорения процесса обучения. Он учитывает историю изменения весов и стремится к более точному определению скорости обучения.

* __Adam__ — модифицированный метод оптимизации, сочетающий в себе идеи Momentum и RMS Prop. Он учитывает среднее и дисперсию gradients для более точного определения скорости обучения.

* Attention mechanism — это инструмент, который помогает модели моделировать внимание к различным частям текста. Это позволяет моделимашинному обучению более точно интерпретировать текст и учитывать информацию, которая имеет наибольший влияние на решение задачи. * __RNN__ — **Recurrent Neural Network**, модели с рекуррентной связью, которые могут обучаться на последовательных данных.

* __LSTM__ — **Long Short-Term Memory**, модификация RNN, которая обладает способностью обновлять и удалять информацию из памяти, позволяя модели обучаться более длинным последовательностям.

* __Attention__ — механизм внимания, который позволяет модельмамонтированному вниманию к различным частям входных данных, учитывая их значение в контексте всей последовательности.

* __Transformer__ — модульный подход к обучению, основанный на модели внимания, который улучшает производительность на NLP задачах благодаря использованию позиционной кодировки и масштабируемости.

* __One-to-One__ — задача, в которой каждому входу соответствует один выход.

* __Seq2One__ — задача, в которой вход представляет собой последовательность, а выход — один выход.

* __Seq2Seq same__ — задача, в которой вход и выход — последовательности одного размера.

* __Attention__ — интуиция состоит в том, чтобы для каждого выхода выбирать наиболее важные входы, игнорируя менее важные.

* __Encoder-decoder__ — архитектура модели, состоящая из энкодера и декодера, где энкодер преобразует входную последовательность в представление, а декодер восстанавливает исходную последовательность из представления.

* __Multi-head attention__ — метод, который применяет несколько различных аспектов внимания к входу, чтобы получить более полное представление.

* __Positional Encoding__ — информация о позиции в тексте, которая добавляется к эмбеддингам токенов, чтобы модели могли учиться на последовательностях.

* __BERT__ — **Bidirectional Encoder Representations from Transformers**, модульный подход к обучению, который использует внимание и позиционную кодировку для обработки последовательностей.

* __Encoder-Decoder__ — модульный подход к обучению, который применяет внимание и позиционную кодировку для обработки последовательностей.

* __GPT-X__ — **Generative Pre-trained Transformer-X**, модульный подход к обучению, который использует внимание и позиционную кодировку для обработки последовательностей. 1. **Encoder-only** — модели, использующие толькоEncoder.
2. **Encoder-decoder** — модели, использующие both Encoder и Decoder.
3. **Decoder-only** — модели, использующие только Decoder.


* __BERT__ = Bidirectional Encoder Representations from Transformers

BERT имеет следующие характеристики:

- **L = 12, H = 768, A = 12, Total Parameters = 110M**
- **BERTBase**: L = 12, H = 768, A = 12, Total Parameters = 110M
- **BERTLarge**: L = 24, H = 1024, A = 16, Total Parameters = 340M

BERT используется для обучающих задач, таких как **Masked Language Modeling (MLM)**, где 15% токенов повреждаются, и следующее предложение заполнено.

BERT является одним из самых популярных моделей NLP, и его реализации значительно расширяются с развитием технологий.

* **Attention mechanism** — механизм внимания, который позволяет модели анализировать последовательность слов с учетом их взаимосвязей.

* **Self-attention** — механизм внимания, который применяется к самому себе (self-attention).

* **Multi-head attention** — несколько уровней внимания, каждый из которых анализирует входную последовательность слов.

* **Encoder-decoder architecture** — архитектура, которая использует два сектора: encoder (вход) и decoder (выход).

* **Encoder** — часть сети, которая преобразует входную последовательность слов.
