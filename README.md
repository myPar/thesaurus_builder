### Пайплайн построения тезауруса

Данный проект предназначен для автоматического построения тезауруса курса по ML. Тезаурус строится на базе текста, извлечённого из видео лекций и pdf-файлов, с последующим форматированием при помощи LLM и удалением дубликатов через сравнения эмбеддингов определений.

### Установка

1. Склонируйте репозиторий
```bash
git clone https://github.com/myPar/thesaurus_builder.git
cd thesaurus_builder
```
2. Установите зависимости
```bash
pip install -r requirements.txt
```

Для транскрибирования видеозаписей лекций я использовал [pisets](https://github.com/bond005/pisets) разработанный [Иваном Бондаренко](https://github.com/bond005) и его командой. Для его работы вам стоит создать отдельное python-окружение, поскольку там могут быть несовместимы версии torch и других библиотек.

#### Шаг 1
Установить [pisets](https://github.com/bond005/pisets) и произвести транскрибирование видео как указано в инструкции репозитория.

#### Шаг 2
Скопировать полученные .srt файлы и .pdf файлы лекций в одну дирректорию __input_files__. 

Пайплайн отсеивает дубликаты, поэтому лучше упорядочить файлы так, чтобы первые были те, где определения даются впервые, чтобы отсеивались дублирующие определения из последующих файлов.

#### Шаг 4
##### форматирование через LLM
Рекомендую использовать хотя бы 14B модель, например [Qwen2.5-14B-Instruct](https://huggingface.co/Qwen/Qwen2.5-14B-Instruct). Пайплайн инферит её для форматирование заэкстракченного текста с специализированным few-shot промптом.

запустите следующую команду:
```
python llm_formatter.py --dir_path='input_files' --output='llm_output' --model_path='Qwen/Qwen2.5-14B-Instruct'
```
Результатом в **output** будут .md файлы со списками определений.
#### Шаг 5
##### удаление дубликатов и формирование тезауруса

Дубликаты удаляются по семантической близости отдельных определений через трансформерные эмбеддинги модели [FRIDA](https://huggingface.co/ai-forever/FRIDA). Используется префикс 'paraphrase: '.

запускаем следующую команду:
```bash
python thesaurus_builder.py --dir_path='llm_output' output='.'
```

результатом будет итоговый .md файл с тезаурусом.
