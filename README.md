### Пайплайн построения тезауруса

Данный проект предназначен для автоматического построения тезауруса курса по ML. Тезаурус строится на базе текста, извлечённого из видео лекций и pdf-файлов, с последующим форматированием при помощи LLM и удалением дубликатов через сравнения эмбеддингов определений.
